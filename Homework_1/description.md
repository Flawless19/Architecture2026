# DESCRIPTION

## SPOF
Я вижу глобально 1 SPOF: gateway. Мы просто не перенаправим никакие запросы, если он по каким-либо причинам отвалится. 
Недоступность остальных сервисов не повлечет за собой каскадный отказ другого функционала.
Возможно, как второй SPOF можно указать веб-приложение, потому что это приведет к недоступности всей системы для продавцов и операторов поддержки т.к. у них нет альтернативы в виде мобилки.

## Диаграмма
№
Элемент диаграммы
Описание и назначение в контексте решения

1
Покупатель
Основной пользователь системы, который просматривает каталог товаров, осуществляет поиск, добавляет товары в корзину, оформляет заказы, оплачивает и отслеживает доставку. 

2
Продавец
Представитель компании или частное лицо, которое размещает товары на платформе, управляет ценами, остатками на складе и характеристиками товаров. Обеспечивает наполнение каталога актуальными предложениями.

3
Оператор поддержки
Сотрудник компании, который помогает пользователям решать проблемы покупателей.

4
МаркетХаб
Основная система маркетплейса, которая объединяет всех участников. Предоставляет: каталог товаров с поиском и фильтрацией, корзину и оформление заказов, интеграцию с платёжными системами, интеграцию со службами доставки, личные кабинеты покупателей и продавцов, администрирование заказов и пользователей.

5
Платежный шлюз
Внешний сервис для оплаты заказов.

6
Службы доставки
Внешние системы курьерских служб и логистических компаний (например, СДЭК, DHL). Получают информацию о заказах, формируют заявки на доставку, отслеживают статусы отправлений, предоставляют трек-номера для покупателей.

7
CRM
Внешняя система управления взаимоотношениями с клиентами (например, Salesforce, Bitrix24). Хранит профили клиентов

№
Элемент диаграммы
Описание и назначение в контексте решения

1
Покупатель
Пользователь, который просматривает каталог, оформляет заказы и оплачивает покупки. Взаимодействует с системой через веб-приложение или мобильное приложение.

2
Продавец
Представитель бизнеса, управляющий товарами, ценами и остатками. Взаимодействует только через веб-приложение.

3
Оператор поддержки
Сотрудник компании, помогающий пользователям. Взаимодействует с системой через веб-приложение.

4
Платежный шлюз
Внешняя система для обработки платежей. Обеспечивает безопасное списание средств, подтверждение оплаты и возвраты.

5
Службы доставки
Внешние логистические компании. Получают информацию о заказах, формируют заявки на доставку, предоставляют трек-номера.

6
CRM
Внешняя система управления взаимоотношениями с клиентами. Хранит профили клиентов и историю заказов для маркетинга и аналитики.

7
Email-сервис
Внешний сервис для отправки email-уведомлений.

8
Push-сервис
Внешний сервис для отправки push-уведомлений.

9
Веб-приложение
Фронтенд для всех типов пользователей. Обеспечивает интерфейс для просмотра каталога, оформления заказов, управления товарами и администрирования. Отправляет запросы к API Gateway.

10
Мобильное приложение
Клиентское приложение только для покупателей. Предоставляет мобильный интерфейс для просмотра товаров, оформления заказов и получения уведомлений. 

11
API Gateway
Единая точка входа для всех клиентских запросов. Выполняет маршрутизацию запросов к соответствующим сервисам, аутентификацию и авторизацию, ограничение количества запросов (rate limiting), кэширование частых запросов.

12
Сервис каталога
Основной сервис для управления товарами. Отвечает за CRUD операции с товарами, поиск и фильтрацию товаров, управление категориями, работу с медиа-файлами (изображения, видео), кэширование популярных товаров в Redis, интеграцию с объектным хранилищем. 

13
Сервис заказов
Обрабатывает весь жизненный цикл заказа: создание заказа из корзины, изменение статусов заказа (оплачен, собран, отправлен, доставлен), отмену заказов, интеграцию со службами доставки, публикацию событий о заказах в очередь для асинхронной обработки. 

14
Сервис платежей
Инициирование платежей через внешний шлюз, обработку подтверждений оплаты, обработку возвратов. 

15
Сервис уведомлений
Специализированный сервис для отправки уведомлений: потребляет события из очереди сообщений, отправляет email через внешний сервис, отправляет push-уведомления в мобильное приложение, управляет шаблонами сообщений.

16
Сервис пользователей
Управляет пользователями и аутентификацией: регистрация и вход, управление профилями, синхронизация данных с CRM. 

17
База данных: товары
PostgreSQL для хранения структурированных данных о товарах: названия, описания, цены, характеристики, категории, остатки, ссылки на медиа-файлы. 

18
База данных: заказы
PostgreSQL для хранения заказов и связанных данных: состав заказа, статусы, суммы, адреса доставки, история изменений. 

19
База данных: клиенты
PostgreSQL для хранения пользовательских данных: логины, пароли (хэши), контактная информация, роли, предпочтения. 

20
Объектное хранилище
Хранилище MinIO / S3 для бинарных файлов: изображения товаров, видео-обзоры, документы. Используется сервисом каталога для чтения/записи медиа-файлов.

21
Кэш каталога
Redis для кэширования: популярные карточки товаров, результаты поисковых запросов, списки товаров в категориях. Используется сервисом каталога и API Gateway для ускорения ответов.

22
Очередь сообщений
Асинхронная шина RabbitMQ для обмена событиями между сервисами (сервис заказов публикует события, сервис уведомлений потребляет), отказоустойчивость (события сохраняются до обработки).
